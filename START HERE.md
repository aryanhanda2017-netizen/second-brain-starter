# Start here

This is a starter second brain for your business: a folder of plain files that holds how your business really works, so AI can use it instead of asking you every time.

It's the same shape as mine. Mine is full. Yours starts empty, and the interview prompt fills the first page tonight.

## What's in it

- **INTERVIEW PROMPT.md**: the prompt that fills your first page. You paste it into Claude or ChatGPT, and it interviews you, one question at a time.
- **Your rules**: the decisions only you make, one rule per line. Start here.
- **Your voice**: how you write, so what AI drafts for you sounds like you.
- **Your clients**: one file per client, with what to remember about them.
- **Your jobs**: one step-by-step playbook for each job you hand to AI.
- **CLAUDE.md**: tells Claude how to use the folder if you open it in Claude Code or Cowork. Ignore it otherwise.

## Tonight: three steps

1. **Download the folder.** On GitHub, click the green "Code" button, then "Download ZIP". Unzip it somewhere you'll find it again.
2. **Run the interview.** Open INTERVIEW PROMPT.md, copy the prompt into a new chat in Claude or ChatGPT, and answer out loud. It takes about 20 minutes.
3. **Save your page and use it.** Paste the finished page over everything in "Your rules/rules.md". Next time you ask AI for anything about your business, give it that page first.

## Every day after that

- **Quickest:** paste your rules page at the top of a new chat, then ask.
- **Better:** make a Project in Claude or ChatGPT and add the files from this folder to it. Every chat in that Project reads them, so you never paste anything again.
- **Keep it growing:** when you catch yourself making a decision nobody else could have made, run the interview again with your page pasted under the prompt. Five minutes, one more rule.

## Keep it private

These files are for you. Don't put passwords, bank details or other people's private information in them.
