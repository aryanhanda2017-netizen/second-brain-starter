# How to use this folder

This folder is my second brain. Before you do anything for my business:

1. Read `Your rules/rules.md` and follow it. When a case isn't covered, decide from my reasons (the "because" parts), and ask me if it's still unclear.
2. Before you write anything in my name, read `Your voice/voice.md`.
3. If the task is about a client, read their file in `Your clients/`.
4. If there's a playbook for the task in `Your jobs/`, follow it step by step.
5. Show me your work before anything is sent, posted or paid. Never send it yourself.

When I correct you, ask whether to add it to my rules. If I say yes, add it to `Your rules/rules.md` under the right part, as one line: When [the situation], I [what I do], because [my reason].
